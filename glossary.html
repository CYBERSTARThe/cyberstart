Cybersecurity Glossary

Learn the important terms, technologies, attacks, and concepts used in cybersecurity.

Authentication

The process of verifying that someone or something is really who or what it claims to be.

Security

Authorization

Determines what an authenticated user or system is allowed to access or do.

Identity

MFA

Multi-Factor Authentication requires two or more verification methods to access an account.

Security

Encryption

Converts readable information into protected data that requires a key or method to decrypt.

Security

Hashing

Converts data into a fixed-length value called a hash. Hashing is commonly used to protect passwords and verify data.

Security

Firewall

A security system that monitors and controls network traffic based on defined rules.

Security

IP Address

A numerical address used to identify a device or network interface on a network.

Network

VPN

A Virtual Private Network creates an encrypted connection between a device and a network service.

Network

DNS

The Domain Name System translates domain names such as example.com into IP addresses.

Network

Packet

A small unit of data sent across a computer network.

Network

Phishing

A scam that attempts to trick people into revealing information or interacting with something unsafe.

Attack

Spear Phishing

A targeted phishing attack designed for a specific person or organization.

Attack

Social Engineering

Manipulating people into revealing information or taking actions that could create a security risk.

Attack

Brute Force Attack

An attack that repeatedly attempts possible passwords or authentication values until one works.

Attack

DDoS

A Distributed Denial-of-Service attack attempts to overwhelm a service with large amounts of traffic.

Attack

Spoofing

An attacker disguises information or identity to make something appear trustworthy or legitimate.

Attack

Man-in-the-Middle

An attacker secretly interferes with communication between two parties.

Attack

Malware

Malicious software designed to disrupt systems, steal information, or perform unwanted actions.

Malware

Ransomware

Malware that prevents access to data or systems and attempts to pressure victims into paying money.

Malware

Spyware

Software designed to secretly collect information about a person or system.

Malware

Trojan

Malware that disguises itself as legitimate software or files to trick someone into running it.

Malware

Worm

Malware capable of spreading between systems, often without requiring the user to manually install it.

Malware

Botnet

A collection of compromised devices that can be controlled by an attacker.

Malware

Antivirus

Security software designed to detect, block, and remove certain types of malicious software.

Security

Zero-Day

A previously unknown or unpatched security vulnerability that may be exploited before a fix is available.

Security

Vulnerability

A weakness in software, hardware, configuration, or processes that could potentially be exploited.

Security

Patch

A software update that can fix bugs, improve features, or address security vulnerabilities.

Security

Penetration Testing

Authorized security testing designed to identify weaknesses in systems and applications.

Security

Incident Response

The process of detecting, analyzing, containing, and recovering from cybersecurity incidents.

Security

Least Privilege

A security principle where users and systems receive only the access they need to perform their tasks.

Security

Password Manager

A tool that securely stores and helps manage passwords and other authentication information.

Identity
