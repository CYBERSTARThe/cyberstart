📖 Cybersecurity Glossary

Explore important cybersecurity terms and learn what they mean.

Showing 100 cybersecurity terms

1. Authentication

The process of verifying that someone or something is who they claim to be.

2. Authorization

The process of deciding what an authenticated user is allowed to access or do.

3. Antivirus

Software designed to detect, prevent, and remove malicious software.

4. Backup

A copy of important data stored separately so it can be recovered if the original is lost.

5. Botnet

A network of compromised devices controlled by an attacker.

6. Brute Force

An attack that repeatedly tries different passwords or keys until one works.

7. CAPTCHA

A test designed to help determine whether a user is human rather than an automated program.

8. Certificate

A digital document used to help verify the identity of a website or other system.

9. Cipher

An algorithm used to transform readable information into an encoded form.

10. Cloud Security

Practices used to protect data, applications, and systems hosted in cloud environments.

11. Cookie

A small piece of data stored by a website in a user's browser.

12. Cryptography

The use of mathematical techniques to protect information.

13. DDoS

A distributed denial-of-service attack attempts to overwhelm a service with large amounts of traffic.

14. Data Breach

An incident where protected or private information is accessed or exposed without authorization.

15. Data Encryption

Converting readable information into an encoded form to help protect it.

16. Digital Certificate

A credential used to help establish the identity of a digital service.

17. Digital Forensics

The examination of digital devices and data to investigate security incidents.

18. DNS

The Domain Name System translates domain names into network addresses.

19. Domain

A human-readable name used to identify a website or other internet service.

20. Endpoint

A device such as a computer, phone, or tablet connected to a network.

21. Exploit

A technique or code that takes advantage of a vulnerability in a system.

22. Firewall

A security system that monitors and controls network traffic according to rules.

23. Hash

A fixed-length value created from data using a hashing algorithm.

24. Hashing

The process of converting data into a fixed-length hash value.

25. HTTPS

A secure version of HTTP that uses encryption to protect web traffic.

26. Identity

Information that represents a person, device, or system in a digital environment.

27. Incident Response

The process of detecting, responding to, and recovering from cybersecurity incidents.

28. Insider Threat

A security risk caused by someone with authorized access to an organization's systems or information.

29. IP Address

A numerical address used to identify a device on a network.

30. Key

Information used by cryptographic algorithms to encrypt or decrypt data.

31. Keylogger

Software or hardware designed to record keystrokes.

32. Least Privilege

A security principle where users and systems receive only the access they need.

33. Malware

Software designed to harm systems, steal information, or perform unwanted actions.

34. MFA

Multi-factor authentication requires two or more types of verification.

35. Network

A group of connected devices that can communicate with one another.

36. Network Security

Methods used to protect networks and the information moving through them.

37. OAuth

A framework that allows applications to receive limited access to resources without receiving a user's password.

38. Operating System

Software that manages a computer's hardware and provides services for applications.

39. Patch

A software update designed to fix bugs or security vulnerabilities.

40. Password Manager

A tool that securely stores and helps manage passwords.

41. Penetration Testing

Authorized security testing designed to identify weaknesses in systems.

42. Phishing

A scam that attempts to trick people into revealing information or taking an unsafe action.

43. Port

A numbered communication endpoint used by network services.

44. Ransomware

Malware that can prevent access to data or systems and demand payment.

45. Risk

The possibility that a threat could take advantage of a vulnerability and cause harm.

46. Router

A device that directs network traffic between different networks.

47. Rootkit

Malicious software designed to maintain unauthorized access while hiding its presence.

48. Sandbox

An isolated environment used to safely run or test software.

49. Security Policy

A set of rules and guidelines for protecting systems and information.

50. Social Engineering

The use of manipulation or deception to influence people into taking an action.

51. Spam

Unwanted messages, often sent in large quantities.

52. Spyware

Software that secretly collects information about a user or device.

53. SSL

An older security protocol that helped protect internet communications and was replaced by TLS.

54. Threat

Something capable of causing harm to a system, network, or information.

55. Threat Intelligence

Information about threats that helps organizations understand and respond to attacks.

56. TLS

A cryptographic protocol used to protect communications over networks.

57. Trojan

Malware that disguises itself as legitimate software or files.

58. Two-Factor Authentication

A type of MFA that uses two different verification factors.

59. URL

A web address used to locate a resource on the internet.

60. VPN

A virtual private network that can create an encrypted connection between a device and a network service.

61. Vulnerability

A weakness that could potentially be exploited to compromise a system.

62. Worm

Malware capable of spreading between systems without requiring the same type of user action as many other infections.

63. Zero-Day

A vulnerability that is unknown or has not yet received an available security fix.

64. Access Control

Security measures that determine who or what can access resources.

65. Adware

Software that displays unwanted advertisements and may sometimes track user activity.

66. Air Gap

A security measure that physically or logically separates a system from other networks.

67. Attack Surface

The collection of possible points where an attacker could attempt to enter or affect a system.

68. Availability

The principle that authorized users should be able to access information and systems when needed.

69. CIA Triad

A cybersecurity model based on confidentiality, integrity, and availability.

70. Confidentiality

The principle of keeping information accessible only to authorized people or systems.

71. Integrity

The principle of keeping information accurate and protected from unauthorized changes.

72. Credential

Information used to prove identity or gain access to a system.

73. Credential Stuffing

An attack that attempts to use stolen username and password combinations on other services.

74. Decryption

The process of converting encrypted information back into readable form.

75. Encryption

The process of converting readable information into an encoded form.

76. Honeypot

A system designed to attract and monitor suspicious activity.

77. IDS

An intrusion detection system monitors activity for possible security threats.

78. IPS

An intrusion prevention system can detect and help block suspicious network activity.

79. Log

A record of events or activities generated by a computer system or application.

80. Logging

The process of recording events and activities for monitoring or investigation.

81. MITM

A man-in-the-middle attack occurs when an attacker secretly interferes with communication between parties.

82. Packet

A small unit of data transmitted across a network.

83. Password Spraying

An attack that tries a small number of common passwords against many accounts.

84. Payload

The part of malicious code or an exploit responsible for performing an intended action.

85. Privilege Escalation

An attempt to gain higher levels of access than originally authorized.

86. Proxy

A service that acts as an intermediary between a user or device and another service.

87. SIEM

A security information and event management system collects and analyzes security-related data.

88. SOC

A security operations center monitors and responds to cybersecurity events.

89. Token

A piece of digital information used to represent authorization or identity.

90. Vulnerability Scan

An authorized scan designed to identify potential weaknesses in systems.

91. Whitelist

A list of approved users, applications, devices, or other items.

92. Blacklist

A list of blocked or untrusted users, applications, devices, or other items.

93. Bot

An automated program that performs tasks over a network or computer system.

94. MAC Address

A hardware identifier associated with a network interface.

95. Subnet

A smaller logical section of an IP network.

96. TCP

A networking protocol designed to provide reliable delivery of data.

97. UDP

A networking protocol that sends data without establishing the same type of connection used by TCP.

98. SQL Injection

A vulnerability where untrusted input can interfere with database queries.

99. Cross-Site Scripting

A web security vulnerability involving untrusted content being executed in another user's browser.

100. Zero Trust

A security approach that continuously verifies access rather than automatically trusting users or devices.
