📖 Cybersecurity Glossary

🔐 Authentication

Definition: The process of verifying who or what is attempting to access a system.

Example: Logging into an account with a password or another verification method.

🛡️ Authorization

Definition: Determining what an authenticated user or system is allowed to access.

Example: An employee may be allowed to view certain files but not administrative settings.

🎣 Phishing

Definition: A social engineering technique that attempts to trick people into revealing information or taking an unsafe action.

Example: A fake message pretending to come from a legitimate organization.

🦠 Malware

Definition: Malicious software designed to perform harmful or unwanted actions.

Examples: Viruses, worms, ransomware, and spyware.

💰 Ransomware

Definition: Malware that can prevent access to data or systems and demand payment from victims.

🔑 Encryption

Definition: The process of transforming readable data into a protected form using cryptographic methods.

Example: Encryption can help protect information while it is being transmitted or stored.

#️⃣ Hashing

Definition: A process that converts data into a fixed-length value using a hash function.

Example: Hashing is commonly used to verify data integrity and securely handle passwords.

🌐 IP Address

Definition: A numerical address used to identify a device or network interface for network communication.

Example: A device on a network may have a private IP address assigned by its router.

📡 DNS

Definition: The Domain Name System translates domain names into IP addresses.

Example: It helps your device find the server associated with a website name.

🧱 Firewall

Definition: A security control that monitors and filters network traffic according to defined rules.

🔌 Port

Definition: A logical communication endpoint used by network services.

Example: Different network services can use different port numbers.

🔓 Vulnerability

Definition: A weakness in software, hardware, configuration, or a process that could potentially be exploited.

⚠️ Exploit

Definition: A method or technique that takes advantage of a vulnerability.

🔧 Patch

Definition: An update designed to fix bugs, security vulnerabilities, or other problems.

🕳️ Zero-Day

Definition: A previously unknown or unpatched security vulnerability that may be actively exploited before a fix is available.

🔐 MFA

Definition: Multi-Factor Authentication requires multiple types of verification when accessing an account.

Example: A password combined with a verification code from an authentication app.

👤 Social Engineering

Definition: Techniques that manipulate people into revealing information or performing actions.

🧩 CIA Triad

Definition: A fundamental cybersecurity model consisting of three goals:

Confidentiality: Protect information from unauthorized access.

Integrity: Keep information accurate and protected from unauthorized changes.

Availability: Make information and systems accessible when needed.

🚨 Incident Response

Definition: The process organizations use to detect, investigate, contain, and recover from cybersecurity incidents.

☁️ Cloud Security

Definition: Practices and technologies used to protect cloud-based systems, applications, and data.

🧪 Sandbox

Definition: An isolated environment used to safely test software or analyze potentially risky behavior.

📊 SIEM

Definition: Security Information and Event Management systems collect and analyze security-related events and logs.

🕵️ SOC

Definition: A Security Operations Center is a team or facility responsible for monitoring and responding to security events.

🔒 VPN

Definition: A Virtual Private Network creates an encrypted connection between a device and a VPN service or network.

📜 Protocol

Definition: A set of rules that defines how systems communicate with each other.

Examples: HTTP, HTTPS, DNS, and TCP.

🧑‍💻 Endpoint

Definition: A device that connects to a network, such as a computer, phone, or server.
