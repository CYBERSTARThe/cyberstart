Cybersecurity Glossary

Learn important cybersecurity terms and understand what they mean.

Account Security

Authentication

The process of verifying the identity of a user, device, or system.

Account Security

Authorization

The process of determining what an authenticated user or system is allowed to access or do.

Network Security

Firewall

A security control that monitors and controls network traffic according to defined rules.

Threats

Malware

Software designed to perform harmful or unwanted actions on a computer or other device.

Social Engineering

Phishing

A type of social engineering attack that attempts to trick people into revealing information or performing an unsafe action.

Data Security

Encryption

The process of transforming readable data into a protected form so that it cannot be easily understood without the appropriate method of decryption.

Data Security

Hash

A fixed-length value produced from data by a hashing algorithm. Hashes are commonly used to verify data and help protect stored passwords.

Security

Vulnerability

A weakness in a system, application, network, or process that could potentially be exploited.

Threats

Exploit

A technique, code, or method that takes advantage of a vulnerability.

Malware

Ransomware

A type of malware that can prevent access to data or systems and may demand payment from its victims.

Network Security

DDoS

A distributed denial-of-service attack attempts to overwhelm a service or system with large amounts of traffic or requests, making it difficult for legitimate users to access.

Account Security

MFA

Multi-factor authentication requires two or more different types of verification before access is granted.

Security Principles

Least Privilege

The principle of giving a user, application, or system only the permissions necessary to perform its required tasks.

Security Principles

CIA Triad

A basic cybersecurity model consisting of Confidentiality, Integrity, and Availability.
